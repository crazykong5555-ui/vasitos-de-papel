# 🔥 ALGORITMO PARA SUBIR REACT A FIREBASE

---

## ✅ FASE 1 — Crear cuenta e iniciar sesión

### Paso 1️⃣ — Entrar a Firebase

1. Ir a 👉 [https://firebase.google.com](https://firebase.google.com)
2. Clic en **“Go to Console”**
3. Iniciar sesión con tu cuenta de Google

---

### Paso 2️⃣ — Crear Proyecto

1. Clic en **“Add Project”**
2. Nombre del proyecto:

   ```
   mis-perros-react
   ```
3. Desactivar Google Analytics (opcional)
4. Clic en **Create Project**
5. Esperar que termine

---

## ✅ FASE 2 — Instalar Firebase CLI

### Paso 3️⃣ — Instalar Node.js (si no lo tienes)

Verifica:

```bash
node -v
npm -v
```

Si no lo tienes, descargar desde 👉 [https://nodejs.org](https://nodejs.org)

---

### Paso 4️⃣ — Instalar Firebase CLI

En la terminal:

```bash
npm install -g firebase-tools
```

Verificar:

```bash
firebase --version
```

---

## ✅ FASE 3 — Login en Firebase (MUY IMPORTANTE)

### Paso 5️⃣ — Iniciar sesión en Firebase

```bash
firebase login
```

Se abrirá el navegador:

✔ Selecciona tu cuenta Google
✔ Permitir acceso

Si todo sale bien verás:

```
✔ Success! Logged in as tuemail@gmail.com
```

---

## ✅ FASE 4 — Preparar Proyecto React

### Paso 6️⃣ — Entrar al proyecto

```bash
cd mis-perros
```

---

### Paso 7️⃣ — Compilar el proyecto React

🔥 Esto es OBLIGATORIO antes de subirlo:

```bash
npm run build
```

Se crea una carpeta:

```
/build
```

Esa es la que se sube a Firebase.

---

## ✅ FASE 5 — Inicializar Firebase en el proyecto

### Paso 8️⃣ — Inicializar Firebase

```bash
firebase init
```

Selecciona:

```
❯ Hosting
```

Luego:

* Use existing project → selecciona `mis-perros-react`
* Public directory → escribe:

```
build
```

* Configure as SPA? → escribe:

```
Yes
```

* Overwrite index.html? → escribe:

```
No
```

Esto es importante para React Router.

---

## ✅ FASE 6 — Deploy (Subir el sitio)

### Paso 9️⃣ — Subir a Firebase

```bash
firebase deploy
```

Si todo sale bien verás algo como:

```
✔ Deploy complete!
Hosting URL: https://mis-perros-react.web.app
```

🔥 Ese es tu sitio web en internet.

---

# 🌎 Resultado Final

Tu página estará disponible en:

```
https://mis-perros-react.web.app
```

o

```
https://mis-perros-react.firebaseapp.com
```

---

# 🔥 COMANDOS RESUMEN (RÁPIDO)

```bash
npm install -g firebase-tools
firebase login
cd mis-perros
npm run build
firebase init
firebase deploy
```

---

# ⚠️ IMPORTANTE PARA REACT ROUTER

En `firebase.json` debe existir esto:

```json
"rewrites": [
  {
    "source": "**",
    "destination": "/index.html"
  }
]
```

Firebase normalmente lo crea automáticamente si respondes **Yes** a SPA.
